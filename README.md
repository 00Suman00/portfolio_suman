# 🚀 Suman Sarkar — Portfolio Website

A sleek, scroll-driven dark luxury portfolio website built with pure HTML, CSS & JavaScript.

---

## ✨ Features

- **Scroll-Scrubbed Background Animation** — 240 video frames rendered on canvas, scrubbing with scroll for a cinematic experience
- **Zigzag Floating Nav Pills** — Four independent floating navigation icons (About, Projects, Services, Contact) with distinct colors and sine-wave float animations in a zigzag layout
- **Achievements Section** — Placeholder achievement cards with "Coming Soon" badges and smooth hover effects
- **Tech Side Decorations** — Animated circuit-board canvas on both sides with glowing nodes, connecting lines, and scrolling binary text
- **Transparent Glassmorphism Footer** — Frosted-glass footers with dim yellow ambient glow
- **Dark Luxury Aesthetic** — Crimson & obsidian color palette, Bebas Neue headings, micro-animations throughout
- **Fully Responsive** — Works across desktop and tablet viewports

---

## 🛠 Tech Stack

| Layer      | Technology                                |
|------------|-------------------------------------------|
| Structure  | HTML5                                     |
| Styling    | Vanilla CSS (no frameworks)               |
| Logic      | Vanilla JavaScript (ES6+)                 |
| Icons      | Font Awesome 6                            |
| Fonts      | Google Fonts (Bebas Neue, Outfit, Caveat) |
| Animation  | Canvas API + requestAnimationFrame        |
