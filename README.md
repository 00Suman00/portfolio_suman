## ✨ Features

- 🎥 **Scroll-Scrubbing Video** — 240-frame background animation driven by scroll position using `<canvas>` and `requestAnimationFrame`
- 🫧 **Zigzag Floating Nav Pills** — 4 independently animated navigation icons (About, Projects, Services, Contact) in a zigzag pattern with per-color accents
- ⚡ **Circuit Board Side Decorations** — Animated tech aesthetic canvas panels on both sides with glowing nodes, circuit lines, and scrolling binary text
- 🏆 **Achievements Section** — Placeholder milestone cards (Coming Soon) with lock badges and animated status indicators
- 🌗 **Glassmorphism Footers** — Transparent frosted-glass footer with dim yellow ambient glow
- 📱 **Responsive** — Mobile-friendly layout
- 🔗 **Stay Tuned Pages** — Placeholder redirect page for upcoming sections

## 🚀 Getting Started

Clone and serve locally:

```bash
git clone https://github.com/00Suman00/portfolio_suman.git
cd portfolio_suman
npx serve . -l 3000
```

Then open **http://localhost:3000** in Chrome.
